# Font App

Local-first font comparison app for preparing client-ready font option images.

## Setup

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Run On A Phone Or Tablet

Connect the mobile device to the same Wi-Fi network as this computer, then run:

```bash
npm run dev:host
```

Open the Network URL printed by Vite on the mobile device.

## Build For Local Use

```bash
npm run build
npm run preview
```

The app has no backend, database, Vercel requirement, hosted API, or CDN font dependency. After dependencies are installed, the app uses local code, preset system fonts, and any font files you upload in the browser session.
